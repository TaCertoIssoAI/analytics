# BigQuery Schema / Schema BigQuery

---

## 🇺🇸 English

This document describes in detail the schema of the main BigQuery table used to store the fact-checking analyses performed by the bot.

### Fields Overview

| Field | Type | Mode | Description |
|-------|------|------|-------------|
| `claims` | RECORD | REPEATED | List of claims identified in the user's message, each with its verdict, sources, and reasoning |
| `final_comment` | STRING | NULLABLE | Final comment generated by the AI at the end of the complete analysis |
| `analysis_metrics` | RECORD | NULLABLE | Aggregated analysis metrics with counts and scores per verdict category |
| `overall_verdict` | STRING | NULLABLE | Overall verdict of the analysis (e.g., VERDADEIRO, FALSO, FORA_DE_CONTEXTO, INVERIFICAVEL) |
| `scraped_links` | RECORD | REPEATED | List of external links that were scraped during the verification process |
| `processed_at` | TIMESTAMP | NULLABLE | Date and time when the analysis was processed and saved |
| `source_type` | STRING | NULLABLE | Source type of the message (e.g., whatsapp, web) |
| `user_message_text` | STRING | NULLABLE | Original text of the message sent by the user to the bot |
| `media_info` | RECORD | NULLABLE | Information about media (image, video, audio) attached to the user's message |
| `analysis_title` | STRING | NULLABLE | Automatically generated title for the analysis |
| `full_combined_text` | STRING | NULLABLE | Full combined text used to generate the embedding (includes title, claims, verdicts, etc.) |
| `document_id` | STRING | NULLABLE | Unique identifier for the document/analysis |
| `embedding` | FLOAT | REPEATED | Semantic embedding vector with **768 dimensions**, generated by the `gemini-embedding-001` model from Google Vertex AI. Used for semantic similarity search |

---

### RECORD Fields in Detail

#### `claims` (RECORD, REPEATED)

Each element in the list represents an individual claim identified in the user's message.

| Sub-field | Type | Mode | Description |
|-----------|------|------|-------------|
| `claim_id` | STRING | NULLABLE | Unique identifier for the claim |
| `text` | STRING | NULLABLE | Text of the claim extracted from the user's message |
| `verdict` | STRING | NULLABLE | Verdict assigned to this claim (e.g., VERDADEIRO, FALSO, FORA_DE_CONTEXTO, INVERIFICAVEL) |
| `reasoning` | STRING | NULLABLE | AI's reasoning and justification for the given verdict |
| `final_comment` | STRING | NULLABLE | Final comment specific to this claim |
| `topics` | STRING | REPEATED | List of topics/categories associated with this claim (IPTC classification) |
| `sources` | RECORD | REPEATED | Sources used to verify this claim |

##### `claims.sources` (RECORD, REPEATED)

Reference sources used in the verification of each claim.

| Sub-field | Type | Mode | Description |
|-----------|------|------|-------------|
| `title` | STRING | NULLABLE | Source title |
| `citation_text` | STRING | NULLABLE | Cited excerpt from the source used in verification |
| `publisher` | STRING | NULLABLE | Name of the source's publisher/outlet |
| `url` | STRING | NULLABLE | Source URL |

---

#### `analysis_metrics` (RECORD, NULLABLE)

Aggregated metrics calculated from the verdicts of all claims in the analysis.

| Sub-field | Type | Mode | Description |
|-----------|------|------|-------------|
| `total_claims` | INTEGER | NULLABLE | Total number of claims identified in the analysis |
| `true_count` | INTEGER | NULLABLE | Number of claims classified as VERDADEIRO (true) |
| `fake_count` | INTEGER | NULLABLE | Number of claims classified as FALSO (false) |
| `unverified_count` | INTEGER | NULLABLE | Number of claims classified as INVERIFICAVEL (unverifiable) |
| `out_of_context_count` | INTEGER | NULLABLE | Number of claims classified as FORA_DE_CONTEXTO (out of context) |
| `truth_score` | INTEGER | NULLABLE | Score/percentage of true claims |
| `fake_score` | INTEGER | NULLABLE | Score/percentage of false claims |
| `unverified_score` | INTEGER | NULLABLE | Score/percentage of unverifiable claims |
| `out_of_context_score` | INTEGER | NULLABLE | Score/percentage of out-of-context claims |

---

#### `scraped_links` (RECORD, REPEATED)

External links that were accessed and scraped during the verification process.

| Sub-field | Type | Mode | Description |
|-----------|------|------|-------------|
| `url` | STRING | NULLABLE | URL of the scraped link |
| `title` | STRING | NULLABLE | Title of the scraped page |
| `scraped_text` | STRING | NULLABLE | Text content extracted from the page |

---

#### `media_info` (RECORD, NULLABLE)

Information about media attached to the user's message.

| Sub-field | Type | Mode | Description |
|-----------|------|------|-------------|
| `has_image` | BOOLEAN | NULLABLE | Whether the message contains an image |
| `image_uri` | STRING | NULLABLE | Storage URI for the image |
| `image_text` | STRING | NULLABLE | Text extracted from the image via OCR or description |
| `has_video` | BOOLEAN | NULLABLE | Whether the message contains a video |
| `video_uri` | STRING | NULLABLE | Storage URI for the video |
| `video_text` | STRING | NULLABLE | Extracted text or caption from the video |
| `has_audio` | BOOLEAN | NULLABLE | Whether the message contains audio |
| `audio_uri` | STRING | NULLABLE | Storage URI for the audio |
| `audio_text` | STRING | NULLABLE | Transcribed text from the audio |

---

### Embedding Notes

- **Model:** `gemini-embedding-001` (Google Vertex AI)
- **Dimensions:** 768
- **Task type:** `RETRIEVAL_QUERY` for search queries, `RETRIEVAL_DOCUMENT` for document indexing
- **Storage:** Vector of 768 floats stored as a REPEATED field in BigQuery
- **Usage:** Semantic search via cosine similarity between the user's query and indexed documents

### Observacoes sobre o Embedding

- **Modelo:** `gemini-embedding-001` (Google Vertex AI)
- **Dimensoes:** 768
- **Tipo de tarefa:** `RETRIEVAL_QUERY` para consultas de busca, `RETRIEVAL_DOCUMENT` para indexacao de documentos
- **Armazenamento:** Vetor de 768 floats armazenado como campo REPEATED no BigQuery
- **Uso:** Busca semantica por similaridade de cosseno entre a query do usuario e os documentos indexados
