Sua Proposta Refinada

Python for the Commons: Scaling Fact-Checking and Community Building through Socially Responsible AI

Proponente Principal • Equipe RAIA & CodeLab (ICMC-USP)

In an era dominated by information overload and the rapid spread of misinformation, the Python ecosystem serves as a vital bridge between high-level academic research and practical, socially impactful applications. This talk explores the journey of two flagship projects originating from the Institute of Mathematical and Computer Sciences (ICMC-USP) in São Carlos: "Tá Certo Isso AI?" and "Folki." Both initiatives demonstrate how Python-driven development can solve localized community challenges while scaling to national recognition.

"Tá Certo Isso AI?" is a multimodal AI chatbot designed to combat "fake news" directly within WhatsApp. We will dive into its technical architecture, discussing the implementation of Retrieval-Augmented Generation (RAG) to cross-reference user queries against trusted sources. We will explore how the team utilizes Python (FastAPI) and LLM frameworks like LangChain/LangGraph to process text, audio, and images, providing users with evidence-grounded responses.

Complementing this, "Folki" represents the power of collaborative intelligence. Built to centralize fragmented academic data, it transforms the student experience through crowdsourced schedules and automated absence tracking. This portion focuses on building community-driven software, maintaining data integrity, and the supervised application of data mining techniques to improve user productivity.

Key Takeaways

  • Multimodal RAG Architectures: Understanding how to build fact-checking layers using Python, FastAPI, and LLMs.
  • Socially Responsible AI Design: Learning how to implement source citation and evidence-based grounding.
  • Community-Driven Development: Strategies for scaling open-source projects from single-campus tools to multi-institutional platforms.
  • Python for Social Good: Practical insights into leveraging university extension groups to create award-winning technology.
  • Low-Barrier Integration: Techniques for deploying complex AI tools into accessible interfaces like WhatsApp.
